About This Timeline App

This app visualizes historical building and resident data in a timeline format. It is designed to be mobile-friendly and easy to use, with features like collapsible house sections, a scroll-to-top button, and a responsive menu. Data can be loaded from a spreadsheet or CSV file.

Created with ❤️ using Materialize CSS and JavaScript.
